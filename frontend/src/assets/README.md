# Landing page photo assets

The five original photographs referenced by the landing page were not included in the project workspace. Add the supplied, reviewed originals here using these names:

- `hero-coffee.jpg` — coffee cherries; crop out any colour palette strip and watermark only when the source and rights permit it.
- `climate.jpg` — paper strips reading “climate change”.
- `erosion.jpg` — gully erosion exposing tree roots.
- `pest-armyworm.jpg` — caterpillar eating a maize cob.
- `pest-aphids.jpg` — insects under a leaf.

For each source, provide an 800px and 1600px-wide WebP named `<name>-800.webp` and `<name>-1600.webp` (for example, `hero-coffee-800.webp`). Keep the original JPEG beside them. The landing page uses responsive WebP `srcset`s, lazy-loads non-hero photos, and includes descriptive alt text. Missing originals currently render with a flat theme background instead of unrelated stock imagery.
